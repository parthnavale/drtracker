# drtracker

A lightweight project to track doctor appointments and related information. This repository contains HTML, CSS and JavaScript for a small web app.

## Features
- View and manage doctor appointments
- Simple, responsive UI built with HTML/CSS/JS

## Tech stack
- JavaScript
- HTML
- CSS

## Getting started
1. Clone the repo:

   git clone https://github.com/parthnavale/drtracker.git
   cd drtracker

2. Open the app in your browser:

   - If this is a static web app, open `index.html` in your browser.
   - If the project uses a Node.js dev server, run (if package.json exists):

     npm install
     npm start

3. If the app expects local storage or sample data, check the project files for a `data/` folder or `sample.json`.

## Development

- Consider adding a build step or bundler if the project grows.
